# ELSEWHERE Portfolio

An interactive black-and-white portfolio built with Vue 3, Vite, GSAP, and a lightweight WebGL noise background.

## Live site

https://akirinni.github.io/elsewhere-portfolio/

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The optimized static build is written to `dist/`.

## Adjust animation timing

Edit the `TIMING` object near the top of `src/App.vue`. Reduced-motion users skip the animated sequence automatically.
